# Screenshot checklist

Grab these before sharing. Preferred: dark mode, 1440px wide browser, no dev tools open.

- `library.png` - Library page with at least two targets in the list, one target expanded showing multiple sessions.
- `project.png` - Project page open on a finished stack, history strip visible at the bottom, at least two revisions shown.
- `compare.png` - Compare view with two revisions side by side (or the before/after slider). Shows the diff is the point.
- `gallery.png` - Gallery page with a handful of published renders, grid layout.
- `tonight.png` - Tonight planner with a few targets queued, rise/set bars visible.
